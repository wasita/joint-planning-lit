# Planning with others in mind

*Arfaei, N., &amp; Ma, W. J. (2024).* Conference on Cognitive Computational Neuroscience (CCN).

[PDF](https://2024.ccneuro.org/pdf/544_Paper_authored_CCN_2024_Arfaei.pdf)

## Why it's here

The clearest existing instance of joint planning treated as a <em>planning</em> problem rather than a game-theoretic or attributional one. Dyads take turns building a road network to connect cities under a shared budget, over decision sequences up to length 16. The winning model, Collaborative Heuristic Tree Search, predicts the partner's next action using the same value function it uses for itself and evaluates its own moves by simulating the partner's response — joint planning as recursive tree search rather than as equilibrium selection. Fills the gap where hierarchical and resource-rational planning meets two agents.
